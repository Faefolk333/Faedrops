# fædrops

Touch sampler and granular instrument for **New Nintendo 3DS**.

[Download the latest release](https://github.com/Faefolk333/Faedrops/releases/latest) · [Install CIA](https://github.com/Faefolk333/Faedrops/releases/latest/download/faedrops.cia) · [Installation guide](https://github.com/Faefolk333/Faedrops/releases/latest/download/INSTALL.md)

## Install using FBI

Open **FBI → Remote Install → Scan QR Code**:

![Install fædrops](https://github.com/Faefolk333/Faedrops/releases/latest/download/install-qr.png)

The runtime ZIP also supports Homebrew Launcher. Preserve your `/3ds/fae01/` sessions, takes and renders when updating. Eight factory drums are embedded; missing kit files are installed automatically.

A/B/C melodic layers, D drums, live keys, note editing, granular textures, shimmer/reverb/delay, tape, EQ and block-based Arrange.

**Validation:** desktop tests and native builds pass; physical CIA/Wi-Fi installation and console performance still need New 3DS testing. See each release for details.

This repository contains **binary releases and installation assets only**. Source code is maintained privately.
